# Lost & Found System

A modern **Next.js 14 App Router** web application to report lost items, browse found items, and safely reunite belongings with their rightful owners using a secure response validation system.

---

## Features

- **Modern UI**: Clean, responsive interface built with Tailwind CSS.
- **Report & Claim Items**: Post lost or found items with descriptions and photos.
- **Response Validation**: Set a security question for each item (e.g., *"What is the color of the phone?"*) to verify rightful ownership before contact details are revealed.
- **Owner Moderation**: Item owners review claimant answers and can approve or reject claims.
- **Contact Number Unlock**: Once a claim is approved, the owner's contact phone number is unlocked for the claimant.
- **Personal Dashboards**: Manage all your posted items in **My Listings** and track submitted claims in **Responses**.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

---

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **HTTP Client**: Axios
- **Language**: JavaScript (ES6+ / React 18)
